# Cocktail App 🍹

Welcome to the **Cocktail App**! This is a web application where users can search for cocktail recipes by name and explore detailed instructions on how to prepare them. Built with simplicity and functionality in mind, this app utilizes **HTML**, **CSS**, and **JavaScript** to deliver a seamless user experience.

## Features ✨

- **Search Functionality**: Enter a cocktail name to fetch its recipe and instructions.
  
- **Dynamic Ingredient List**: View the ingredients and their measurements in a clean, structured format.
  
- **Responsive Design**: Optimized for both desktop and mobile screens.
  
- **Error Handling**: Displays a helpful message if the input is invalid or empty.
  
- **API Integration**: Fetches data from [TheCocktailDB](https://www.thecocktaildb.com/).

## Technologies Used 🛠️

- **HTML**: Structure of the app.
  
- **CSS**: Styling and layout design.
  
- **JavaScript**: Logic and API interaction.

## How to Run the App 🚀

1. Clone or download this repository to your local machine:
   
   git clone https://github.com/Sivananthini164/Cocktail-App
   
2. Navigate to the project folder and open the index.html file in your browser.
   
3. Start searching for cocktails using the input field!

**How It Works 🔍**

The user enters the name of a cocktail in the input field and clicks the Search button.

The app sends a request to TheCocktailDB API to fetch cocktail details.

The app dynamically displays:

The name of the cocktail.

An image of the drink.

The list of ingredients with measurements.

Instructions for preparation.

If no valid result is found, an error message is displayed.
